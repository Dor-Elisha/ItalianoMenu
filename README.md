# Italiano Menu

סביבת עבודה בסיסית לאפליקציית frontend עם:

- Vite
- React 19
- TypeScript
- ESLint

## הפעלה

```bash
npm install
npm run dev
```

## סקריפטים זמינים

- `npm run dev` - סביבת פיתוח מקומית
- `npm run build` - build ל-production
- `npm run preview` - בדיקת build מקומי
- `npm run lint` - בדיקות lint
